Frequently Asked Questions

Is the root domain "is-a.store" completely free to register?

No. .store is a commercial Top-Level Domain operated by Radix and cannot be registered for ₹0. GitHub Pages only hosts static files on *.github.io — it does not register custom TLDs. Until a paid is-a.store domain or a genuinely free NS-delegated third-level domain (such as eu.org or DigitalPlat dpdns.org) is delegated to Cloudflare DNS, this registry operates transparently in Staging / Indexed Mode.

Why can't I combine CNAME with TXT or MX records on the same subdomain?

Per RFC 1034 §3.6.2 and RFC 2181 §10.1, a CNAME record must be the sole record at a DNS node. Combining it with A, AAAA, TXT, or MX causes resolvers to fail or behave unpredictably. If you need TXT or MX records alongside web hosting, use A and/or AAAA records instead of CNAME.

Can I register a subdomain using only an Android phone?

Yes. Use the Registration Builder above, tap Open in GitHub Editor & Submit PR, and commit directly inside Chrome or any mobile browser. No PC, laptop, Termux, or Git CLI is needed.

How do you prevent subdomain takeovers and phishing?

Automated GitHub Actions block private/bogon IPs, wildcard records, brand-impersonation names, punycode lookalikes (xn--), DNS loops, and mismatched *.github.io CNAMEs. Each user is capped at 3 subdomains, and maintainers can instantly suspend abusive entries to remove them from Cloudflare DNS while locking the name against re-registration.

Where are GitHub secrets or API tokens stored?

Nowhere in the frontend or repository code. Pull-request validation runs with read-only permissions and zero secrets. Cloudflare API tokens exist solely as encrypted GitHub Actions Repository Secrets accessible only on trusted, maintainer-merged main branch runs.
